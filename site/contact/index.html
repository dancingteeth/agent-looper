Contact Agent Looper

Use these channels for Agent Looper (@dancingteeth/agent-looper). There is no phone tree and no sales inbox. Bugs, install failures, runtime questions, and docs gaps belong on GitHub so other people can see the answer.

  • GitHub issues (preferred)
  • Source and pull requests
  • npm package page
  • Author site — Paul Zgordan / dancingteeth
  • The Vacuum Cleaner Gets Smart

If you are an agent recovering from a bad URL, start at llms.txt or the sitemap. For “how do I run this,” use the homepage install steps or pnpm exec agent-loop-init after adding the package.

Do not send secrets, API keys, or Doppler tokens to issues. Redact logs.
