How it works

Frozen GOAL.md → worker (pluggable agent SDK: Cursor, Cline, OpenCode, Pi, Codex, DSH) → shell verify (hard gate, exit 0) → optional judge / reviewGate that only reopens on serious findings. Progress lives in git and files, not chat memory.

Worker

New session every iteration. Implements toward the frozen goal. Progress is the repo — not an accumulating thread.

Verifier

Your shell command. Exit 0 is the only completion truth. Models approve their own work. Exit codes don’t.

Judge optional

After verify passes, writes review.md. With reviewGate, only error + impact findings reopen the fix loop.

You

Write the goal and verify script. Own outcome, scoreboard, permission, and budget. The harness owns the grind.

Install

Node 22+, pnpm. Cursor-only 60-second path — other runtimes below.

terminal 
pnpm add -D @dancingteeth/agent-looper @cursor/sdk

export CURSOR_API_KEY=…   # or: doppler run -- …

pnpm exec agent-loop-init
# edit .cursor/loops/my-task/GOAL.md
# edit verify.sh until `bash .cursor/loops/my-task/verify.sh` is honest

pnpm exec agent-loop run .cursor/loops/my-task --runtime cursor --review-gate

Other runtimes & judge

Worker and judge are independent. Default judge is Cursor (grok-4.6 when worker is Cursor). Point reviewRuntime elsewhere to keep the judge off Cursor quota.

  • Cursor — default worker; needs @cursor/sdk
  • Cline — Pass or Credits via @cline/sdk
  • OpenCode — Go + BYOK via @opencode-ai/sdk
  • Pi — BYOK via @earendil-works/pi-coding-agent
  • Codex — ChatGPT / OpenAI via @openai/codex-sdk
  • DSH — DeepSeek Harness CLI on PATH
